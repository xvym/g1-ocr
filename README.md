# 宝可梦 VC 初代日版实时 OCR 翻译

Windows 本地工具：识别 **3DS VC 日版《宝可梦 红、绿、蓝、皮卡丘》**投屏画面的日文，在独立窗口显示**当前可见内容**的中文翻译。

运行时完全离线，结合日版游戏文本与国际版汉化资源建立本地中文翻译能力。输入前提是设备画面已完整投送到采集软件。

四作共享 OCR 核心和公共文本库，先以红版验证。中文默认沿用既有汉化译文，仅严重偏离原意时修订；开发和建库阶段允许大模型辅助。

优先使用已知点阵字体的严格匹配。采集采用不受其他窗口遮挡影响的窗口采集，自动定位实际游戏区域，人工框选仅作兜底。

已确认采用 Java 8、JavaFX 8 和 JNA 直接调用系统 WGC，不维护自有采集 DLL；Python 用于建库。JNA 与 JavaFX 的标准原生运行库随包提供。

当前已形成设计基线草案，等待共同理解的总确认，尚未开始产品实现。
