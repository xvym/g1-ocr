# 截图素材

本目录保存 3DS VC 日版宝可梦的原始 PNG，用于几何、固定布局和像素字形的开发与验证。产品要求见 [Spec](../pokemon_g1_vc_ocr_SPEC.md)，使用顺序见 [ExecPlan](../execplan.md)。

## 输入条件与索引

- 共 108 张 PNG，尺寸均为 1200×720。
- 采集条件：VC 原生 1:1 GB 显示，投屏按 3 倍点对点放大，图像包含 VC 外壳。
- [manifest.csv](manifest.csv) 为逐文件索引，字段为 `sample_id`、`file`、`width`、`height`；文件路径相对本目录。ID 用于标注和报告，新增材料分配新 ID，不重新编号已有条目。
- 索引只记录原始材料事实。全部图片的目标日文见 [文本档案](labels/japanese.md) / [机器可读答案](labels/japanese.json)，标注来源及比较规则见 [标注说明](labels/README.md)；建档不代表产品识别已验收。各文件的准确游戏版本须在有来源依据时另行标注。
- 截图文件名中的时间只用于定位文件，不是连续帧时间戳；不能据此计算触发延迟或漏帧。

完整上屏 `k=3` 时，GB 候选裁剪为 `(360,144,480,432)`，再还原为 160×144。先核对单个原图的范围及网格相位；该示例不得直接用于任意实时窗口。原始图像保留不动，裁图与规范化图像作为派生输出单独保存。

## 能验证的内容

- 上屏/GB 几何关系、k=3 裁剪、网格与字形质量。
- 固定区域、文字行列、数字/光标列、清浊点与遮罩位置。
- 人工核对字符后，对独立样本统计原始 OCR；核对语料后检查单张图的日中对应。
- 无框、空框、相似布局及遮挡的静态行为。

仅靠这些静态图片无法证明：逐字过程、短暂停顿、闪烁/滚动的时序、提前/遗漏/重复触发比例、实际端到端延迟，以及遮挡后实时捕获仍更新。相关验证按需补充有真实时间戳的连续输入与实机检查，不以重复图片代替真实时序证据。

## 标注与结果

- 先对全部 108 张建立日文文本档案，允许模型直接目视转录；当前档案为 103 张含目标文字、5 张无目标文字或只有空框，合计 206 行目标文字。模型标注不冒称人工复核，未知字符显式待核对，不补隐藏内容。
- `labels/` 保存独立答案，包括样本 ID、区域、可见日文、选择/数值、空框/无目标预期和标注状态；几何坐标与遮罩可在实现布局时补齐。答案不进入运行时产品资源，不由待测 OCR 自动定稿。
- 同段对话、近似重复画面按组划分开发/保留组；最终全部 108 张都须有结果，所有目标区域纯视觉日文及附属退出文字正确率为 100%，CER=0，全图完全正确 108/108；不能用词典纠错或排除难例达到门槛。
- 中文翻译是最终验收目标，中文标注和通过条件暂列待定，不阻塞本批日文验收，也不能由日文通过推定中文通过。
- 需要连续材料时在 `sequences/` 保存来源引用、真实时间戳与片段边界；构造序列明确标记，不能充当实机采集证据。
- 报告引用原图与样本 ID；大量裁图、帧和缓存放输出目录，不覆盖原 PNG，不为每次检查复制整套素材。
