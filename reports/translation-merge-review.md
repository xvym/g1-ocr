# 同文译文合并可行性审阅

## 结论

**42组中，41组可以统一显示译文，1组暂缓处理。** 这里的合并指为相同日文语义单元确定共同的显示译文，并保留各自的来源记录和后续对白。

| 分类 | 数量 | 处理方式 |
| - | -: | - |
| A：可直接统一现有译文 | 31 | 同义措辞、语气或排版差异，选择兼容全部上下文的现有版本；其中6组仅标点/排版不同 |
| B：选较准确的现有版本后统一 | 8 | 避开漏译、误译或增译，不能任取一个候选 |
| C：拟定中性新译文后统一 | 2 | 现有版本不宜互套，中性表达可以兼容全部上下文 |
| D：来源异常暂缓 | 1 | 先处理汉化增文或来源对齐问题 |
| 合计 | 42 | A+B=39组可采用库内版本；A+B+C=41组可统一 |
