# S4 中文运行时开发验证

日期：2026-10-21，版本 0.3.0。范围为本地语料运行时、离线入口和 JavaFX 接入。用户已要求暂缓真实 new3ds_view 验收；本轮不执行真实投屏或桌面 WGC 测试。

## 实现

- `TextCorpus` 读取带 BOM、带多行/双引号字段的 CSV，不依赖第三方仓库、网络、截图答案或模型服务。主记录与行窗口保留全部来源，不合并重复台词。
- 全部来源、可见行序和固定正文共同约束候选，无需确认或选择游戏版本；只有批准的四组同形假名等价。`rawOcr`、候选、`resolvedJapanese`、中文和来源分开输出。字符前缀保留可能来源，尚未完整时不发布完成译文。
- 每个候选独立确定当前中文、可见变量及语义类型、前文要求与后文等待条件；全部当前结果一致时输出 `equivalent`，保留全部来源。比较只针对允许显示的当前范围，全文不同不妨碍当前相同片段发布；译文或显示条件有实际差异仍为 `ambiguous`。未完成或缺前文/变量的候选不能被忽略。
- `TextResolver` 只截取保存的 Unicode 码点范围。单元待完成时回显日文；需要滚动前文时，必须已观察到同源相邻窗口。逐字前缀不补出未出现的事实，也不擦除仍匹配的有效前文。
- `slot_rules.csv` 补充 26 条实际需要的变量类型规则，来源是固定日版源码。姓名/昵称长度遵循日版常量，数量、盒号、等级与名称来自当前 OCR；昵称即使与词条同文也不强译。招式/道具等已核对类型用精确词条；未知角色 RAM 保留字面值。缺少中文所需的姓名或数值仍回显日文，不沿用历史变量。
- 字段类型按实际生产者区分：交换物种、固定道馆城市/馆主与昵称分别绑定；PC 取消控制行不走昵称路径，数量保留可见空格和原始后缀。固定退出词来自原汉化。
- 战后说话者组合由实际 trainer 宏和保存战后指针生成，支持局部标签，继承正文分段与前文/等待条件。化石研究的已知错译在保存的分段状态中阻止发布，未自动改原汉化。
- 战斗组合只使用保存的模板；使用招式按 `move_symbols/default_set` 检查语法分组。敌方前缀与昵称分开，前缀来自同版本既有汉化，不重写昵称。
- 物品词条保留的 `#` 缩写在显示时按同版本已有的“宝可梦”词条展开；原中文及片段下标不变，先截取保存范围再展开，当前变量不参与控制符替换。
- `LiveSession` 沿用会话/映射/区域/内容代次撤下过期显示；停止、切窗、重校准、捕获失效、空框或区域消失清理译文/前文。新稳定结果才更新翻译，选择位置仍独立更新。
- JavaFX 提供独立对话/列表面板和原始日文页签，版本选择已取消；选定允许内容后由字体布局换行。原始 OCR 同形候选仍可查看，来源与修订在详情中保留。离线入口只接受图片、上屏原点、倍率、输出目录五个参数。

## 独立开发答案与完成口径

`src/test/resources/chinese-cases.json` 的预期由模型根据日文文本、固定汉化来源与已批准修订编写，未从待测运行结果生成，不冒称人工复核。中文按来源字面比较，不改标点、全角数字或措辞；只有动态变量按当前输入展开。

本阶段检查要求：

1. 同时核对来源匹配状态、分段就绪状态和中文全文；任何一项不同均失败。
2. 来源唯一或全部候选当前结果一致且语义/变量条件满足时，只发布已保存范围；未完成、缺前文、缺变量或候选结果实际冲突时中文必须为空。
3. 覆盖多来源等价与出处保留、不同译文冲突、候选显示条件冲突、全文不同但当前片段相同、用户修订、礼貌语省略、滚动/前缀、失效、历史姓名禁用、盒号/昵称顺序、组合招式及未知字。
4. 另以实际固定 PNG 串联 OCR 与翻译，检查列表数量、PC 昵称/等级、战斗菜单和原始 OCR 未变；纯日文仍须满足全部 108 张门槛。

此口径只适用于已列出的开发场景。它不是全部 108 张中文答案，也不定义未确定的最终 A6 覆盖率或性能门槛。
