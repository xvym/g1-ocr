# 同文日中译文差异静态审计

2026-10-22，合并前静态快照。以下数量来自当时工作区CSV和匹配实现；审计未启动应用、运行OCR或动态测试，也未修改语料。静态口径及合并前文件SHA-256见 [JSON](translation-variants.json)。后续41组已获用户确认并应用，当前状态另见[应用记录](translation-merge-applied.json)，不将此快照当作合并后冲突数量。

## 与问候句最相近的数量

**42组独立对白文本**：40组无变量文本、2组原生姓名变量文本。其完整对应日文单元相同，当前保存范围及所需槽位具备，但有不同的汉化显示文本。它们对应58种可见窗口/模板键。

去重方式：先将三份来源及同文地点保留为候选、按日文归组；同一语义文本的不同滚动/行窗口归为一组；11种带说话者的 `TrainerEnd.*` 组合复用已有正文，不重复算独立问题。例如当前问候句有21条来源，且有「おーす！」与完整两行两种窗口，最终算1组独立文本。

这42组并不都可直接选择同一译文。6组的差异仅限标点、换行等非文字内容；其余36组仍须区分自由译法、语义差异、漏译及汉化增文/来源异常，不把它们标成已确认同义。

后续[逐项语义审阅](translation-merge-review.md)已完成：31组可直接选现有版本、8组须选较准确的现有版本、2组采用中性新译文，共41组已按用户确认统一显示译文；1组汉化名单替换异常暂缓。原来源及后续对白保留；57个相关保存窗口的中文静态一致，当前资源未执行新的动态测试。

## 全库较宽统计

扫描10,187条主记录、23,939条已保存片段；其中运行时会加载10,072条主记录（8,362条对白、1,710条词条），对白有22,087个来源窗口，归并为7,306种日文/模板键。

同一可见日文/模板键具有不同保存中文的有 **152组**，涉及1,241条来源窗口。每组可有多个地点/来源，不把这些来源行当独立文本数。

| 分类 | 可见窗口/模板键数 | 含义 |
| - | -: | - |
| 无变量、对应完整日文单元相同 | 45 | 归为40组独立文本 |
| 带变量、对应完整日文单元相同，当前所需槽位具备 | 13 | 其中11组是上面正文的带说话者组合；另外2组为原生姓名变量文本 |
| 无变量、当前窗口相同但完整日文单元不同 | 57 | 多为共用开头/中间句，需要上下文，不能统一成一条译文 |
| 无变量、涉及缺当前变量的候选 | 9 | 5组有可显示/缺变量条件冲突；4组全部缺变量，不会仅因保存中文不同而被判候选译文冲突 |
| 其他带变量窗口碰撞 | 28 | 包括不同内容的共同开头、缺当前变量等，不能只按日文模板同文直接选译文 |
| 合计 | 152 | 以上分类互斥 |

模板共41组：30组仅从槽位存在性看所需变量均在当前模板中，9组混合缺变量、2组全部缺变量；这里没有枚举具体名字/物种/道具/招式值，因此不保证每个模板在某一实际输入上都成为竞争候选。

如果只按整段主记录统计，相同日文全文有不同中文全文的是22组对白、128条来源记录。这个口径会漏掉长对白开头的问候差异，也可能计入未发布的增文，不能与42或152相加。

词条另有1组同类型差异：`エリートトレーナー` 分别为「精英训练家♂」「精英训练家♀」。角色/性别无法由这个词本身区分时，应单独处理；它在变量翻译中可能保留日文，并不一定呈现对白的ambiguous状态。「ゴースト」的「鬼斯通／幽灵」分别属于物种名与属性，运行时按类型查找，不把这组跨类型同形当作翻译冲突。

## 具体例子

| 完整日文 | 当前中文变体 |
| - | - |
| おーす！／みらいの チャンピオン！ | 哟！／未来的冠军！；嗨～！／未来的冠军！；等你很久喽！／未来的冠军！ |
| こんちわ！ | 你好！；您好！ |
| にもつが いっぱいだ | 行李已满了。；行李已满了！ |
| くやしく ないもん | 我不后悔。；我才没有不甘心！ |
| …… はははーッ！／ゆうれい や むし くらい だぜ！ | 有倒是有。／那就是幽灵属性和虫属性！；有倒是有。／那就是虫属性！ |
| ！ | ！；宝可梦第一世代／红蓝绿/黄 汉化人员名单……（完整161字保存在清单） |

其中「幽灵属性和虫属性／只有虫属性」涉及实际漏译；「！」与汉化人员表的对应属于增文或来源异常。它们都需要实质核对，不能当普通语气差异合并。

6组仅标点/排版差异为：省略号、啊的呼喊符号、行李已满、华蓝馆主水属性台词的换行、钓鱼爱好句尾标点、广播提示音标点。这里只描述中文字符顺序未变，未授权自动改写这些来源。

## 统计边界

- 日文分组采用运行时的空白处理、NFC及批准的四组同形假名等价；中文按实际保存切片及同源 `#` 展开比较，保留措辞与标点。
- 关联完整日文单元来自 `segments.csv` 的日文起止行序和当前窗口保存的语义单元索引，未用待测识别结果生成答案。
- 这是语料静态差异清单，**不是所有实际运行时歧义的总数**。未枚举任意变量填值、不同变量名模板之间的重叠、逐字前缀、组合语法过滤或已观察前文消歧。
- 本次只生成审计报告；问候句及其他译文未被自动统一，原图、字库、主库、分段和匹配代码均未改。
