# 手机离线审阅入口

1. 将本目录的 index.html 下载到手机；它可以放在任意目录。
2. 用支持 JavaScript 的浏览器打开这个 HTML，页面标题应含“手机离线入口”。
3. 点击“选择资料 ZIP”，选择已经下载的完整 gt-all-scenes-v2 目录 ZIP，或包含它的 GitHub 仓库 ZIP。无需解压；之前下载、包含原审阅包的旧仓库 ZIP 也能使用。
4. 等待“资料包已连接”，再切换场景、原帧与状态；点击资料链接会在页面下方显示原附件。

文件只在本机读取，页面没有上传或网络请求。原图和附件读取时按原审阅清单核对 SHA-256。大型 ZIP 只读取目录和当前需要的文件，不整包解压到内存。支持普通 ZIP 的存储和 DEFLATE 压缩；不支持加密、分卷和 ZIP64。若浏览器提示不支持解压，可更新浏览器，或重新用“仅存储/不压缩”打包原审阅目录。

本入口对应 gt-all-scenes-v2，原清单 SHA-256 为 3f800da7ce58e00a3b0ca5e4d443beeb0629d3d87f40118f43c22100f452241e。原 GT、原帧、范围、评分契约和待验证缺口均未修改；本入口不授予批准或冻结。安卓实机显示尚待验证。
