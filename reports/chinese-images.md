# 全部图片中文问题：根因、修复与验证

日期：2026-10-21，开发版本 0.3.0。7 类实现/语料缺口已修复；1 处原汉化语义错误已阻止输出，具体订正待用户确认。全部语料统一匹配，无需选择游戏版本。

## 根因与修复范围

| 问题 | 根因 | 处理 | 状态 |
| - | - | - | - |
| CI-01 | 固定词提取白名单遗漏开始菜单退出标签；运行时无可检索词条 | 从 StartMenuExitText 与 data.xlsx 的原汉化同角色词提取 关闭，保留来源 | 已修复 |
| CI-02 | 数量正则只接受乘号后紧邻数字，且由匹配结果重新拼装原文 | 名称与数量分离，接受可见排版空格，后缀按原始子串保留 | 已修复 |
| CI-03 | 将 PC 区域用途误当成每一行的字段用途，取消行也走昵称路径 | 带可见等级的宝可梦行保留昵称，独立控制行只查固定取消词 | 已修复 |
| CI-04 | 源正文没有包含游戏 PrintEndBattleText 拼接的姓名前缀，局部目标标签也被漏收 | 依据 trainer 宏与保存战后指针生成 1043 个带前缀组合，继承正文语义边界 | 已修复 |
| CI-05 | 把重复使用的 wNameBuffer 当作无类型字面量，没有沿 GetItemName 数据流确定语义 | 为 AIBattleUseItemText.RAM3 记录有源码依据的 item 角色 | 已修复 |
| CI-06 | 城市和馆主名被当作字面量或可变姓名，固定地名/馆主词条未被提取 | 按 wGymCityName/wGymLeaderName 区分固定角色，并提取8座道馆的原汉化词条 | 已修复 |
| CI-07 | 用 MonName 名称子串推断昵称，混淆由物种ID生成的交换名称 | 按交换缓冲区的实际生产者判为 pokemon，已确认昵称缓冲区继续原样保留 | 已修复 |
| CI-08 | 所选原汉化把研究化石写成研究宝可梦，离线语义审核曾误标 aligned | 在保存的语义单元中标记 source_semantic_mismatch，所有重叠窗口拒绝发布 | 已阻断，订正待确认 |

修复落在提取规则、字段职责和源码数据流上，没有按图片编号或单个词做运行时替换。数量解析适用于所有道具；固定取消行与带等级的昵称行分别处理；物种、道具、固定馆主/城市和昵称分别绑定。仍保留全部来源，不修改原始 OCR，不使用截图答案识别。

## 静态来源核对

- 新增 51 个有原汉化出处的固定词条：三份来源各 1 个退出词、8 个道馆城市和 8 个馆主。
- 新增 1,043 个战后组合：红绿/蓝各 348 个，皮卡丘 347 个。分别覆盖 30/30、30/30、34/34 处保存战后指针的调用，以及 310、310、305 个 trainer 宏生产者；全局/局部标签均解析。只组合实际被战后流程引用的正文，目标丢失时建库失败。
- 已逐条检查所有组合的前缀/正文来源与正文语义边界、等待/前文状态，未因添加说话者提前释放正文。交换物种类型规则覆盖三份来源的 45 个槽位；道具角色追溯至 `GetItemName`。
- 原有 9,093 条主记录的日文及中文正文均未改，CSV 列序保留。元数据只改变 3 个前缀记录的组成状态，以及 3 个化石研究记录的已知错译状态。图像、字库、日文独立答案未改。
- 当前资源为 10,187 条主记录、23,939 个窗口、15,700 个语义单元；来源对应问题为 0，已知语义错译涉及 3 条来源记录、6 个窗口，均阻止发布。

静态逐项检查、作用范围、源码/资源哈希及产物哈希见 [根因证据 JSON](chinese-root-fixes.json)。早期 `text-corpus-static.json` 保留原快照，不冒充当前资源证据。

## 动态验证

完整构建成功，7 项测试通过、1 项桌面 WGC 测试跳过。16 组既有开发场景的 24 次比较通过；另在运行修复前按独立日文及固定汉化来源编写了 11 张受影响原图、23 个单元的中文/状态预期，全部通过。它们是定向回归答案，明确为模型编写，非人工复核或完整 A6 答案。

每张原图独立经过规范化、区域检测、纯视觉 OCR 和匹配，不从文件名推测前文。全部 108 张已重跑：

## 保留条件与待确认订正

无中文不是统一故障：4 张实际歧义为 g1-002、061、064、104；等待语义单元、缺少滚动前文、缺当前姓名和昵称保留仍按 Spec 处理，不能强选来源或借用历史变量。79 张“就绪”也不代表完整中文独立验收通过，最终 A6 答案与门槛仍待落实。

g1-106 的原汉化“我致力于研究／罕见的宝可梦的啰！”与日文研究罕见化石的含义矛盾。当前三个来源、六个相关窗口均保存 `source_semantic_mismatch`，不再发布这处错译；其他正确语义单元继续使用。已提出仅将“宝可梦”替换为“化石”的具体订正，保留换行及其余措辞。依据 [Spec R8.2](../pokemon_g1_vc_ocr_SPEC.md)，原汉化订正须逐项确认，当前尚未应用该替换。
