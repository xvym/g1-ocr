# 验收数据、指标与失败归因

状态：工程验收方案，随总设计提交最终确认；尚未运行产品测试。目标值已确认，本文将其转成可复现的计数和计时规则。

## 数据集与独立真值

现有 `testpic/pic/` 的 16 张 645 × 580 PNG 是初始回归集：对白、战斗、背包、商店、PC 各 3 张，菜单 1 张。它们没有采集软件边框，也没有时间序列，不能证明实时采集、完整字库、四作或全游戏覆盖。

实施时分开保留开发集和冻结验收集。先枚举六类场景的文字结构、变量、必要版本变体及风险矩阵，再固定样本清单、哈希、预期区域/原文/中文/变量、可见范围、时间轴、场景权重和排除规则。具体数量依据来源清单和真实可取得的独立序列确定，写入验收清单；缺少对应范围的证据就报告未验证，不能宣称全范围通过。

真值需要独立检查原始图像、游戏来源和中文绑定；不能由实现自己的识别或错误渲染器生成后原样当答案。人工或大模型辅助标注可以批量进行，争议、审阅和修正留下记录。调参后发现真值错误须单列变更及理由，重新固定版本，不能静默删掉失败样本。

数据分为四组：字库与可控渲染验证、独立真实游戏静态图/序列、带已知矩形的窗口内容定位样本、实际 WGC 窗口生命周期测试。相同文字的缩放/配色变体单独报告鲁棒性，不扩张语义覆盖率分母。合成数据不能替代真实输入，静态数据不能替代动态系统行为。

## 必测矩阵

| 类别 | 最低需覆盖的变化 | 核对内容 |
| --- | --- | --- |
| 字形及归一化 | 普通/战斗附加字形、浊点/半浊点、共享假名、数字标点、未在初始图出现的字符；原生、整数、非整数缩放，采样相位及中间色 | 精确位图和正确字形标识；未知字形明确失败，不输出近似字符 |
| 游戏区域 | 工具栏/侧栏/背景、内部黑区、无字、全黑转场、窗口内移动、尺寸/DPI变化、多候选 | 矩形和变换正确；不裁游戏内容、不吸收非游戏文字；不确定时人工兜底 |
| 对白 | 逐字打印、跨页、保留上一行的滚动、快速连续翻页、姓名插入、不同汉化分页 | 只显示已见含义，不泄漏后文、不混页 |
| 战斗 | 各布局、名字/昵称、连续 HP 和数值、命令菜单、等待箭头 | 最新可靠数值和同次关联字段，游标与正文分开 |
| 背包/商店 | 名称、数量/金额、列间空格、滚动、确认子菜单 | 当前行项及价格关系，屏幕外条目不补齐 |
| PC/菜单 | 父子遮挡、多窗口组、开关、选择变化、长中文 | 只识别可见部分，关联组原子提交，相对位置及完整阅读 |
| 四作与资源 | 共享模板、必要版本变体、无英文桥接、重复标签、源宏/变量差异、严重语义补丁 | 不依赖错误标签/行号对应，不因共享去重丢变体 |
| WGC 生命周期 | 部分/完全遮挡、移动、缩放、最小化恢复、关闭重开、反复启停、支持环境的 DPI变化 | 帧有效范围、恢复定位、目标身份、资源释放，不积压旧帧 |
| 离线发布 | 无开发工具、随包运行时、断网、来源/哈希完整性 | 无运行时网络依赖，完整资源包可独立运行 |

严格字形关卡必须包含现有 645 × 580 图和实际窗口采集，不能只演示原生像素。支持范围内失败应保留并修复；不能为通过而把非整数放大或含中间色样本改成不支持。

## 指标单位与公式

基本单位是预先标注的“可见阅读事件”：某区域或关联组在一段有效时间内展示一份应阅读内容。重复帧、游标闪烁、同一句的重复提交不增加事件。新页、新列表项或语义变化形成新事件；数字连续动画作为预先标注的序列用例，检查可靠中间值与稳定终点，不按视频帧制造数千个成功样本。

设有效标注事件总数为 N，系统在该事件仍有效期间提交了新鲜、完整且自动接受结果的事件数为 A，其中所有自动提交的中文、变量、位置和可见范围均正确的事件数为 C。某事件只要有一次错误自动提交即不能计入 C，稍后改正不抹掉错误。

另设 U 为没有对应真值阅读事件的错误自动输出事件数，例如空白画面中的虚构译文、额外区域或提前显示未见内容。按预先标注的负样本时间窗和区域归并持续相同误输出，不能按重复帧扩大计数；归属已有阅读事件的错误只降低该事件的 C，不重复计 U。负样本窗口及所有自动提交必须审计，不能只评估有正文的截图。

| 指标 | 计算与要求 |
| --- | --- |
| 自动覆盖率 | A/N，目标 ≥98%；这里只统计系统已接受输出，错误另由正确率约束 |
| 自动输出正确率 | C/(A+U)，目标 ≥99.5%；额外误输出进入分母，同时列出每次错误，不能用后续正确覆盖掩盖 |
| 正确自动覆盖率 | C/N，辅助报告，避免单看覆盖率误解实际效果 |
| 资源覆盖率 | 有正确原文、可见绑定和中文资源的事件数/N；与运行识别分开 |
| 严格字形还原率 | 正确全等字形数/标注可见字形数，并报告“全字形均正确”的区域比例 |
| 显示延迟 | 见下文，目标 P95 ≤300 ms；同时报告未输出、错输出及超时数 |

兜底日文、等待、暂停快照、旧译文暂留、人工选择翻译均不算 A。手动 ROI 测试与默认自动 ROI 测试分别标记，不能用人工定位结果声称自动定位通过。按规则保留未知姓名原文、其余模板已准确翻译，可以作为正确结果。

凡以“当前译文”呈现的自动内容都进入审计，不能仅因内部没有打完整标记就漏掉部分错译。暂留旧译文只能在已确认的时间和状态规则内作为展示例外；超时或错误更新同样进入失败判定。

同一事件内的部分正确或部分显示不能充作完整成功；独立区域可分别形成事件，必须在冻结清单中先定义粒度。各场景报告 N/A/C/U、全部失败码和延迟分布，总体权重在调参前固定。无自动结果或样本不足时显示未达到/证据不足，不能报告无定义的百分数为通过。

快速翻页仍需核对实际输出是否错误或泄漏后文。短暂不完整、尚未形成可读内容的逐字过程用于过程测试，不强行计为完整阅读事件；划分由独立标注决定，不能因为算法没赶上就事后删掉事件。

## 时间定义与显示确认

t0 为该事件的稳定、完整、有效画面在采集端首次可获得的时间；不包含 3DS 到采集软件的上游延迟。稳定由真值时间轴决定，不由算法自己宣布稳定才起算。逐字打印未完成的时间另记，等待确认、轮询、复制、识别、匹配、队列和界面呈现均计入 t1−t0。

[SystemRelativeTime](https://learn.microsoft.com/en-us/uwp/api/windows.graphics.capture.direct3d11captureframe.systemrelativetime?view=winrt-26100) 是合成器渲染该帧时的 QPC 来源时间，以 [TimeSpan 的 100 ns 单位](https://learn.microsoft.com/en-us/uwp/api/windows.foundation.timespan?view=winrt-26100) 返回，不是原始 QPC ticks，也不直接等于 WGC 首次可取时刻。分别记录来源、取帧和复制完成时间，并与本地单调时钟校准。

正式验收默认以独立真值确定的首份稳定有效画面的来源时间代理 t0，说明与真正可获取时刻的偏差及测量误差；回放使用预定投递时间并核对同一时基。真实采集另作独立画面观测核对。轮询取帧之后才起算会漏掉等待，丢掉首份稳定帧后也不能以更晚保留帧重置事件起点。若代理或显示观测误差足以影响 300 ms 结论，须改进测量后再验收，不能宣称已达标。

t1 为正确且完整译文实际呈现的时间。`Platform.runLater` 入队或执行完毕都不是屏幕已显示的充分证据，JavaFX pulse 记录本身也不能证明屏幕已经呈现。实施时配合独立的显示观测/录制核对建立测量方法，写清分辨率、误差和开销，不能把渲染时间当零。采集预览的降频不改变 t0。

对正确自动输出事件统计 P50/P95/最大值；所有未完成或错输出另外计数并参与覆盖/正确率。另报全部 N 中在 300 ms 内得到正确结果的数量，避免只对少量最快成功样本报告漂亮 P95。旧译文即使恰好相同，也不能替代对当前事件的重新核验。

防闪参数的 150 ms/1 秒是可调初值，完整有效候选确认的 50–80 ms 是待测起点。任何等待都包含在 300 ms 内，不能扣除防闪时间。

## 状态与资源管理专项检查

- 新内容确认后原子替换，中间无主动清空；独立区域不互相阻塞，关联组不混帧。
- 首次不一致超过 150 ms 标记更新中，1 秒到期撤下过时正文；候选反复变化不重置计时。
- 真正无字持续 150 ms 清除；无新帧、定位失败和未知字形不能等同无字。
- 切页、重定位、恢复、重开窗口后，迟到计算不得提交；旧视图暂留不成为新上下文证据。
- 静止画面无需重复渲染；连续数值变化不会无限等待；长中文能完整阅读。
- 没有新 WGC 帧时，已有充分完整证据的当前快照仍可确认；单调时钟继续驱动更新标记与到期，不能等下一帧才撤下超时旧文。
- 多次启停/缩放/恢复比较 COM、GPU、Java 缓冲和线程数量，检查持续增长及退出清理。记录实际观测，不能仅凭有 finally 就宣布无泄漏。

## 失败分类与证据

| 类别 | 例子 | 应修复的位置 |
| --- | --- | --- |
| capture_invalid / environment | 无效纹理、窗口失效、ABI异常 | JNA 绑定、环境与捕获生命周期 |
| roi_unresolved / grid_restore | 游戏矩形或采样相位错误 | 定位、归一化 |
| unknown_glyph / font_profile | 点阵无全等命中、附加字形缺失 | 网格、字体与组合规则 |
| source_gap / unsupported_source_control | 日文缺失或宏未解析 | 提取工具及原文资源 |
| translation_gap / alignment_gap | 无中文或当前片段无法安全绑定 | 配对、补译和显示对齐 |
| ambiguous_match / slot_error | 不同中文无法消歧、姓名或数值错误 | 模板索引与当前证据 |
| stale_commit / display_error | 错页覆盖、提前显示、旧文超时或布局截断 | 代次隔离、状态机与 UI |

每个失败保留数据版本、输入/时间片、预期与实际、区域、代次、候选及复现方法。同类错误聚合后修复并回放，不能把大量异常默认分配给用户手工处理。若严格识别与已确认输入范围确有不可解冲突，带最小证据回到设计讨论，不私自改指标或替换成模糊猜字。
