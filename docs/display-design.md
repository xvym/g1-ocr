# 译文更新与相对位置布局

状态：已确认区域级防闪机制及 150 ms、1 秒的可调初值；相对锚点、中文区域适配、换行和展开完整阅读也已确认。界面采用 JavaFX 8，直接系统采集路线仍须原型验证。

## 区域级提交

每个文字区域维护最后提交结果、正在观察的候选和首次发现内容不一致的时间。新候选尚未完整、尚未通过严格识别与文本匹配时，不直接覆盖已经显示的内容。

已提交内容与当前观测相同则保持；新内容完整且通过稳定性核验后，在一次界面提交中替换文字、变量和来源信息。普通独立区域分别更新；存在遮挡关系的父菜单和子菜单按同一组提交，避免新旧布局叠加。

所有结果绑定采集目标、定位代次、区域身份与观测序号。过期计算结果不得覆盖新位置或新页面。相同中文和相同变量不重复更新界面，来源 ID 变化本身不引起重绘。

## 已确认的防闪规则

| 情况 | 已确认行为 |
| --- | --- |
| 与已提交结果相同 | 保持显示并结束不一致计时 |
| 出现完整有效的新内容 | 连续有效观测确认后整块替换，中间不清空 |
| 逐字打印、滚动或短暂识别失败 | 暂留上一份完整译文 |
| 不一致持续超过 150 ms | 显示稳定的小标记“更新中”，正文不闪烁 |
| 有效画面持续确认区域无文字 150 ms | 清除该区域 |
| 首次不一致后 1 秒仍不能得到当前结果 | 用稳定的等待状态替换旧译文，显示可用的当前原文 |
| 最小化或手动暂停 | 保留最后快照并明确标记暂停；恢复后重新验证 |

150 ms 与 1 秒是已确认的可调初值，不是样本测量结果。新候选反复变化不能重置最长暂留计时；只有确认旧内容仍可见或成功提交当前内容时才结束计时。

旧译文暂留是防闪所需的有限显示例外。它不是当前帧的匹配成功，也不能计入自动覆盖率或用来满足新内容的延迟目标；超出短过渡后需要明确标记。

新的完整可见内容可优先按两次有效观测、约 50–80 ms 的稳定区间进行验证，这是待测起点而非必须等待两个新帧的硬条件。静止窗口可能没有新 WGC 帧；单份有效快照已有严格完整匹配、区域结构及适用的终止/等待证据时，可在稳定窗口内继续核验后提交，不能无限等待新帧。重复相同采集帧不算新增独立证据；也不能仅凭时间经过或两次文字相同就认定逐字打印已经完成。

更新标记、清空和最长暂留由单调时钟驱动，即使没有新帧也必须执行。计时可使用仍有效的快照，但不能把无新帧判作无文字；采集目标状态失效按暂停或失效流程处理。

确认、查表、布局和显示的总过程仍须满足已接受的稳定有效画面到达后 P95 不超过 300 ms。不能把防闪等待从指标中剔除来满足门槛。

## 游标与动态数值

已知位置、已知用途的闪烁游标不计入正文变化，选中位置作为独立属性处理。[原始文本渲染](https://github.com/Narishma-gb/pokegreen/blob/master/home/text.asm) 明确包含等待箭头的绘制与清除，不能把所有三角形一律删除。

HP、金额等变化数值按小区域或槽位更新。连续变化时不能一直等待数值不变；在受控刷新节奏下提交当时最新的严格识别值，并确保关联字段来自同一次有效观测。

## 相对位置布局

原生游戏坐标为 160 × 144。将已识别文字区域保存为归一化矩形，映射到独立面板中，保持左右、上下关系和区域顺序。采集软件的窗口边框、侧栏和桌面坐标不参与译文布局。

已确认保持相对锚点和顺序，按中文可读性适配区域尺寸。文字自动换行；溢出时提供展开完整阅读，字号保持可读，不使用持续缩小或来回重排解决所有情况。碰撞处理需要保证可见内容可读，正文不能静默截断。

若采用 JavaFX 8，[Pane](https://docs.oracle.com/javase/8/javafx/api/javafx/scene/layout/Pane.html) 可按计算坐标放置区域，[TextFlow](https://docs.oracle.com/javase/8/javafx/api/javafx/scene/text/TextFlow.html) 可按宽度换行，普通文本控件可提供完整阅读。AnchorPane 的锚点是边距约束，不会自动变成百分比定位；应用需要计算相对坐标并处理碰撞。

后台生成完整待提交快照后，用一次 [Platform.runLater](https://docs.oracle.com/javase/8/javafx/api/javafx/application/Platform.html) 任务在 JavaFX 线程提交。JavaFX 8 支持这类批量更新，但一致性和过期结果隔离仍由本项目实现。

## 验证场景

必须覆盖对白逐字打印、翻页空白、连续快速翻页、滚动保留上一行、菜单开关、PC 多层遮挡、游标闪烁、HP 连续变化、窗口缩放与最小化恢复。分别测量空白闪动、旧结果最长持续时间、错误页面提交、正确替换延迟及长文本是否可完整阅读。16 张静态样本不足以验收这些时间行为。
